# Luke Brown

**Software Engineer · Founder of Archipelago Software**

I build software end to end, from architecture and backend systems to infrastructure and user interfaces.
I run Archipelago Software, a small software consultancy in Melbourne, Australia.
Outside client work, I develop open-source tools and explore software architecture, systems engineering, and AI-assisted development.

## Selected projects

- **[OpenRelay](https://github.com/lukebrown14-code/OpenRelay)** — An experimental lab for AI coding efficiency, exploring token use, context management, and model routing through reproducible benchmarks and independent task verification.
- **[Delta](https://github.com/lukebrown14-code/Delta)** — An investment research assistant built in Rust, with a terminal interface, evidence stored in SQLite, and cited reports checked against gathered evidence.
- **[Geodex](https://github.com/lukebrown14-code/Geodex)** — A country intelligence dashboard built with Next.js and Supabase, bringing demographic and economic indicators together for side-by-side comparison.
- **[CMD-Todo-List](https://github.com/lukebrown14-code/CMD-Todo-List)** — A lightweight task manager written in C, with a command-line interface and local file storage.

## Current interests

Software architecture and systems design; developer tooling and AI-assisted software engineering.
I’m interested in how open-source software can make engineering more efficient, and how to measure the performance tradeoffs.
